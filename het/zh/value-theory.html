古典价值理论

什么决定商品的长期价格？这是一个专题模块，从斯密的海狸与鹿，到李嘉图的自然价格、马克思的转形问题，再到斯拉法。

本专题内容
  1. 两种价值理论
  2. 斯密：海狸与鹿
  3. 斯密的加总论及其循环
  4. 李嘉图：劳动、过去劳动与自然价格（计算器）
  5. 马克思：从价值到生产价格
  6. 斯拉法、资本与经验证据

1. 两种价值理论

古典经济学家区分了商品的市场价格和自然价格（即它的“价值”）：前者随日常的供求而变动，后者是市场价格围绕其波动的长期平均水平。对于什么决定自然价格，大致有两种回答：

  • 劳动价值论：相对价格最终由生产商品所需的劳动量决定。这是斯密、李嘉图和马克思的传统。
  • 效用价值论：相对价格反映商品给消费者带来的满足。这是萨伊、西尼尔以及后来的边际主义者的传统。

斯密本人就注意到了区分两者的难题。水是生命所必需的，却几乎不花钱；钻石对生存毫无用处，却非常昂贵。使用价值和交换价值可能指向相反的方向。劳动价值论的回答是：寻找和切割钻石需要多得多的劳动。1870年代的边际主义者则会回答：重要的是最后一单位的效用，而水是充裕的（专题8）。

2. 斯密：海狸与鹿

在资本积累和土地私有尚未发生以前的早期未开化社会中，获取各种物品所需的劳动量之间的比例，似乎是能够为相互交换提供某种规则的唯一情况。亚当·斯密，《国富论》，第一篇第六章（1776）

3. 斯密的加总论及其循环

斯密认为，一旦资本得到积累、土地成为私有财产，劳动就不再单独决定价格。产品现在必须支付工资、利润和地租，因此自然价格就是三者按其“自然”（平均）水平之和：

自然价格 = 工资 + 利润 + 地租（各自按社会平均水平计算）

竞争使各行业的工资率趋于相等，也使各资本的利润率趋于相等。假设利润率为10%，两个行业都雇用工人，但行业2每个工人使用的资本是行业1的两倍。那么行业2每个工人必须赚取两倍的利润，它的价格相对于它所使用的劳动就必须更高。价格不再与劳动成比例。

但这个理论有一个逻辑缺口。价格用工资、利润和地租来解释；然而工资、利润和地租本身就是货币额，其大小取决于价格。斯密的理论是用价格解释价格。李嘉图试图回到劳动来打破这个循环。

4. 李嘉图：劳动、过去劳动与自然价格

李嘉图的回答是：一件商品不仅包含了制造它的工人的现在劳动，也包含了生产其工具和原料的过去劳动。在他著名的例子中，袜子的价值包括了种植棉花、运输棉花、建造船只和机器、纺纱、织布和销售的劳动。每一种投入都可以追溯到更早年份所付出的劳动。

然而，利润是随时间累积的。一个一年前就为劳动付了钱的资本家，期望从这笔支出中获得回报；因此，过去劳动付出的时间越早、利润率越高，它在价格中所占的分量就越大。设工资率为 w，利润率为 r：

过去劳动的成本 = Σ（t 年前的劳动）× w ×（1 + r）t

价格 =（现在劳动 × w + 过去劳动的成本）×（1 + r）

下面的计算器使用亨特的数字例子（第5章）。两种商品每单位都包含4小时劳动，因此它们的劳动比率是 1 : 1，但 X 主要使用很久以前的过去劳动，而 Y 主要使用现在劳动。

图中显示了每一个利润率下 X 相对于 Y 的价格。虚线是劳动比率。利润率越高，两者的差距越大。

李嘉图得出、亨特也加以强调的结论是：只要利润率为正，且各商品的劳动在时间上的分布不同，相对价格就会偏离相对劳动量。利润率越高，偏离越大；利润率为零时，价格与劳动恰好成比例。尽管如此，李嘉图仍然认为劳动是相对价格的主要决定因素，利润只是次要的影响。

试一试：把利润率设为0%。然后让 X 和 Y 的劳动在时间上的分布相同。在这两种情况下，价格与劳动之间的差距会怎样？

5. 马克思：从价值到生产价格

马克思把商品的价值分为三个部分：不变资本（C，所耗费的生产资料的价值）、可变资本（V，工资，即劳动力的价值）和剩余价值（S，工人在工资之外创造的新价值）。他的利润率是

r = S / (C + V) = (S/V) / (C/V + 1)

其中 S/V 是剩余价值率，C/V 是资本有机构成。如果两个部门的剩余价值率相同而有机构成不同，那么当商品按价值出售时，它们的利润率就不同。竞争使资本流动，直到利润率相等，此时商品按不同于价值的生产价格出售。说明这一过程如何发生，就是转形问题。

马克思自己的解法是在每个部门的成本上加上平均利润率（40%），但他只把产出按生产价格计价，而投入仍按价值计算。后来的经济学家从拉迪斯劳斯·冯·鲍特凯维兹（1907）开始，同时对投入和产出进行转形。这需要联立求解方程组：

(200·p₁ + 100·p₂)(1 + r) = 400·p₁
(100·p₁ + 100·p₂)(1 + r) = 300·p₂
400·p₁ + 300·p₂ = 700

解得 r ≈ 39.4%，价格见最后一列。总价格仍然等于总价值，但总利润不再恰好等于总剩余价值。这一点对马克思的论证是否重要，从那以后一直争论不休。

6. 斯拉法、资本与经验证据

1960年，皮耶罗·斯拉法出版了《用商品生产商品》，复兴了不依赖效用的古典价格理论。它也揭示了新古典理论的一个问题：“资本”无法作为独立于利润率的单一数量来衡量，因为资本品的价格本身就取决于利润率。在1960年代的剑桥资本争论中，这引出了再转换：同一种技术可能在低利润率和高利润率下都是最有利可图的，因此无法总是把各种技术排列为“资本密集度”更高或更低。保罗·萨缪尔森在1966年承认了这一点。

这里有一个亨特着重指出的讽刺。反对劳动价值论的理由是各部门使用资本的比例不同；而正是同样的差异在新古典理论中造成了再转换。如果所有部门的比例都相同，价格就会与劳动成比例，再转换也就不可能发生。

在实践中，偏离有多大？爱德华多·奥乔亚利用1947—1972年美国的投入产出表（“Values, prices, and wage–profit curves in the US economy”，Cambridge Journal of Economics，1989）发现，基于劳动价值的价格与观察到的市场价格非常接近，测得的工资—利润曲线几乎是直线。后来使用投入产出数据的研究得出了大体相似的结论。理论上的争论仍在继续，但劳动价值与价格之间的经验差距，比单凭理论所推测的要小。

讨论：如果劳动价值能很好地预测市场价格，这是否就解决了劳动价值论与效用价值论之间的争论？一种价值理论还需要解释什么？
