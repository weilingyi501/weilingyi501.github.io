凯恩斯与大萧条

为什么市场经济可能长期陷于大规模失业，以及凯恩斯认为应当为此做些什么。

1. 大萧条与正统的回答

1929年10月华尔街股市崩盘之后，美国经济连续收缩了将近四年。到1933年，实际产出下降了大约四分之一，消费价格下降了约四分之一，大约每四个工人中就有一个失业。数千家银行倒闭。崩溃通过贸易和金融蔓延到欧洲和拉丁美洲。英国在1931年放弃了金本位，美国在1933年开始实行罗斯福新政。

当时的经济学，即凯恩斯所说的“古典”经济学，有一个明确的答案。在竞争性经济中，失业意味着劳动的价格太高。如果货币工资下降，企业就会雇用更多的工人。如果储蓄超过投资，利率就会下降，直到投资增加到足以吸收储蓄。萨伊定律，即供给创造自己的需求的思想，排除了需求普遍不足的可能。

正统观点失业来自过高的工资。灵活的工资和利率会使经济回到充分就业。最好的政策是让价格自行调整，并保持预算平衡。
凯恩斯失业来自支出太少。工资和价格的下降可能使情况更糟。政府应当维持需求，必要时通过借债和投资来实现。

2. 为什么削减工资不能恢复就业

凯恩斯提出了两个论点。第一，工人和雇主就货币工资而不是实际工资讨价还价。如果货币工资下降，价格往往也会下降，因此实际工资可能根本不会下降多少。第二，也是更根本的一点，工资不仅是企业的成本，也是工人用来购买商品的收入。在整个经济中削减工资会削减需求，而面临销售下降的企业不会雇用更多的工人。对一个雇主来说合理的做法，对所有雇主合在一起来说却适得其反：这就是合成谬误。

价格下降还会加重债务的实际负担。欧文·费雪的“债务—通缩”理论（1933）说明了通货紧缩如何迫使借款人削减支出、出售资产，从而进一步压低价格。

3. 有效需求与乘数

凯恩斯认为，产出和就业由有效需求决定：家庭、企业和政府实际支出了多少。家庭把每一美元新增收入的一部分花掉，即边际消费倾向（c），其余的储蓄起来。投资取决于企业对未来的预期，而不取决于家庭储蓄了多少。在最简单的模型中，产出稳定在它等于支出的水平上：

Y = C + I + G，其中 C = a + c·Y  ⟹  Y = (a + I + G) / (1 − c)

1 / (1 − c) 这一项就是乘数。多出的一美元投资或政府支出会成为某个人的收入，其中一部分又被花掉，如此循环往复。

乘数与节俭悖论

节俭悖论：当所有家庭都试图多储蓄时，消费下降，产出和收入下降，最终总储蓄并不比以前多，因为储蓄仍然必须等于投资。对一个家庭来说审慎的做法，可能使整个经济陷入贫困。

试一试：点击“每个人都试图多储蓄50”，比较前后的总储蓄。然后降低边际消费倾向。乘数会怎样变化？

4. 投资、不确定性与动物精神

如果投资推动需求，那么什么推动投资？在《通论》第12章中，凯恩斯认为，企业必须依据极其有限的知识去估计多年以后的收益。实际上，它们只能依靠惯例：除非有理由认为情况会改变，否则就假定现状会持续下去。由于惯例很脆弱，投资可能随着消息和情绪而剧烈波动。凯恩斯把这种不顾不确定性而采取行动的冲动称为“动物精神”。

股票市场并不能解决这个问题。凯恩斯把职业投资比作报纸上的选美比赛：读者要想获胜，就得挑出其他读者会挑选的面孔。投资者试图预测的是一般看法对一般看法的看法，而不是一项资产的长期收益。他区分了企业，即预测资产在整个寿命期内的收益，和投机，即预测市场心理，并警告说，当企业变成投机漩涡上的泡沫时，危险就来了。

5. 流动性偏好与货币政策的局限

在正统的说法中，利率使储蓄与投资相等。凯恩斯则认为，利率是放弃流动性的价格：人们在不确定时把货币作为安全资产持有，而利率是说服他们转而持有债券的东西。在严重的萧条中，无论利率降到多低，人们都可能囤积货币，因此中央银行无法把利率压到足以重振投资的水平。后来的经济学家称之为流动性陷阱；它在1990年代的日本以及2008年后的全世界重新回到了政策辩论之中。

6. 投资社会化及其后续

凯恩斯怀疑仅靠货币政策能否确保充分就业。他在第24章中得出结论说，需要“某种程度的全面的投资社会化”，他的意思是由国家对投资的总体水平负责，而不是工业的公有制。财政政策、公共工程以及公共投资的重要作用都由此而来。

另外两个发展值得了解：

  • 卡莱茨基。波兰经济学家米哈尔·卡莱茨基在1930年代初独立地得出了有效需求原理。在《充分就业的政治方面》（1943）中，他认为企业界领袖可能反对持久的充分就业，因为它会增强工人的议价能力，从而产生政治性的经济周期。
  • 利润与赤字。在卡莱茨基的基础上，海曼·明斯基强调，以简化的形式来说，总利润等于投资加政府赤字加贸易顺差，减去家庭储蓄。当私人投资崩溃时，巨额的政府赤字使利润，从而使企业得以维持。明斯基认为，“大政府”和作为最后贷款人的中央银行，是近来的衰退，包括2008年和2020年的衰退，没有演变成萧条的原因；但这也使风险社会化了，却没有使投资社会化。

战后，希克斯和萨缪尔森等经济学家把凯恩斯的部分思想吸收进“新古典综合”：短期是凯恩斯，长期是瓦尔拉斯（第12周）。琼·罗宾逊等后凯恩斯主义者把这称为“冒牌凯恩斯主义”，认为它丢掉了不确定性和金融的不稳定性，而这些正是凯恩斯著作的核心。

讨论：凯恩斯说，1930年代的问题不是稀缺，而是未能利用现有的资源。这描述的是一个特例，还是资本主义经济通常的运行方式？
